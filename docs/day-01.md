## Core distinctions

### CI

Frequent integration into a shared codebase with automated validation.

### Continuous Delivery

The software is automatically built/tested and kept in a production-ready state. A manual approval can still exist before production.

### Continuous Deployment

A successful pipeline automatically deploys to production without a manual production approval step.

### Artifact

A versioned build output that can be stored and deployed.

Examples:

- JAR
- WAR
- Docker image

Source code and the generated artifact are different things.

### DevSecOps

Security is integrated throughout the software delivery lifecycle rather than being treated only as a final review.

## Key lesson

DevOps is broader than CI/CD. It combines engineering practices, automation, collaboration, feedback, reliability and operational ownership.
